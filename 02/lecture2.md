If we are close with the initial value to $p$ but not equal to $p$, then generate the sequence, we should see similar figures: here, the steps will go away from the neighborhood of the fixed point. And in the case when the derivative is less than $-1$, the graph is decreasing in a small neighborhood of the fixed point, and if you pick an initial point, we will see this spiraling figure, but those points will go away from the neighborhood of the fixed point, so we will not converge to $p$. So this is a local version of the fixed point iteration problem, and what it says is that if we are lucky and we would like to approximate a fixed point where the derivative value in absolute value is less than 1, then there is a chance for that in practice. But we need to find a good initial value which is close enough to $p$ and generate the fixed point iteration sequence from that point, and the fixed point iteration will converge to the limit, and the limit is a fixed point of the function, of course.
* **[[48:23](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=2903)]** If we are not lucky and the derivative is bigger than 1 in absolute value, then the fixed point iteration will not converge to this point, so numerics needs some luck in practice. So what we do is really we try to pick an initial value and generate the fixed point sequence. If we get a convergent sequence, then we are lucky and we are happy that we have a solution of the problem. If we don't get a convergent sequence, we try the same with a different initial point and we try again and again, and if it will not work with many tries, then we should need to do something else—that's the general strategy in numerics: try to do it, and if it does not work, try something else. Okay, so as I said, this looks like a special problem, but in fact, it's really an essential topic in numerics and also in mathematical analysis.

### 2.2 Stopping Criteria of Iterations

* **[[49:52](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=2992)]** In section 2.2, we will talk about stopping criteria of iterations. So in numerics, we have seen that many times we generate an infinite sequence and the limit of the sequence is the solution of the problem. So the question is, we generate a sequence, but which element of the sequence should be used as an approximation of the limit? In other words, where to stop generating the sequence? How to determine the number of steps, okay, which gives us a good approximation of the limit?
* **[[50:51](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=3051)]** But here we will talk about the problem that we are looking for the solution of the equation $f(p) = 0$, so $p$ is the exact solution of this equation, $p$ is the root of the function $f$. There are three natural methods to give a stopping condition: we define tolerance values $\varepsilon_1, \varepsilon_2, \varepsilon_3$, and we stop generating the sequence at the $k$-th step if this is the first condition: $|p_k - p_{k-1}| < \varepsilon_1$. This condition one is the numerical analog of computing the absolute error of the approximation. $p_k$ is the approximation, $p$ is the exact value, but instead of $p$, we use $p_{k-1}$ here in the formula because we don't know $p$, we cannot evaluate the error, and we use the difference of the elements of the sequence—the consecutive elements of the sequence—as the approximation of the error. If this difference is small enough, then we say that this is small because we are close to the limit.
* **[[52:34](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=3154)]** Or we can use the second condition: $\frac{|p_k - p_{k-1}|}{|p_k|} < \varepsilon_2$. And what is the meaning of it? This is a numerical analog of relative error: $\frac{|p_k - p|}{|p|}$. And again, the idea is that if the relative error is small, then this expression will be small because $p_{k-1}$ will be close enough to $p$, so $p_k$ takes the role of $p$ in the formula, and $p_{k-1}$ is used instead of $p_k$ in the formula, so this will be satisfied if $p_k$ is close enough to $p$.
* **[[53:34](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=3214)]** The third condition: we are looking for the root of the function $f$. If at the point $p_k$, the function value is close to zero, absolute value less than $\varepsilon_3$, then we hope that this is less than $\varepsilon_3$ because $p_k$ is close to the root, so then we stop generating the sequence.
* **[[54:02](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=3242)]** Unfortunately, none of the conditions are perfect, and here are some examples. Suppose that we generate the sequence given by this formula, then the difference of the consecutive terms is $1/k$. So when $k$ is big enough, this is automatically small; condition one will hold for large enough $k$. But this is a standard example in calculus for a sequence which goes to infinity; we do not approach a finite limit, okay? So condition one is not correct in the sense that it can be satisfied even in the case when the sequence is not convergent.
* **[[55:07](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=3307)]** Similarly, for the same example, we evaluate the second condition—this ratio—and an easy estimate gives us that it's less than $1/k$ again, and that means it goes to zero as $k \to \infty$. Condition will be satisfied again, but the sequence does not converge.
* **[[55:27](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=3327)]** But we can have a problem with the third condition. Imagine that we have a function $f$ with a graph that looks like this: at the point $p_k$, the function value can be small, smaller than a given $\varepsilon_3$, but the function has no root close to this point. The root of the function may be far away from the point $p_k$. This condition can be satisfied but we are not close to the root of the function. So those are not ideal or not perfect conditions, but those are the conditions which we typically use in practice. And typically, we just use some combination of those conditions: condition one together with three, or the second condition together with a third condition is recommended to use in practice. And when we generate an infinite sequence, we always want to build a maximal iteration number condition into the program code. Let's say we don't want to generate more than 1,000 elements of a sequence because if we do it, probably we have a situation where the sequence is not convergent. So too many iterations are always an indication for the case that maybe we don't have a convergent sequence. Okay, so this is just a few general arguments about stopping criteria.

### 2.3 The Method of Bisection

* **[[58:03](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=3483)]** In section 2.3, we will introduce the method of bisection. Before we do that, let me introduce some notation. This notation will denote the open interval spanned by the real numbers $\alpha$ and $\beta$. So we recall the Intermediate Value Theorem, which is again a basic result in calculus. If we have a continuous function and function value at $a$ not equal to $f(b)$, and we pick a point $d$ in between $f(a|)$ and $f(b)$—here we use the interval spanned by the two function values—then the claim of the theorem says that there exists a point $c$ in the domain of the function such that at the point $c$, the function value equals to the value $d$. You can see the figure here: $f(a) \ne f(b)$, here $f(a) < f(b)$, and pick a value in between the two function values, then there exists a point $c$ in the domain, so in between $a$ and $b$, with the property that the function value at this point equals to the given value $d$. In other words, the continuous function takes any value in between two function values, so that's an important result.
* **[[59:28](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=3568)]** Now we consider the problem of solving a scalar nonlinear equation. Move all the terms to one side of the equation; then the equation can be written in this general form: $f(x) = 0$. And first, we study the method of bisection. The condition which implies the existence of the solution of this equation is the following: if the function value at $a$ and at $b$ are of opposite sign, in other words, the product of the two function values is negative. Again, look at the figure here: the function value at the point $a$ is positive and at the point $b$ is negative, and this condition together with the continuity of the function guarantees that the graph of the function will intersect the x-axis at least at one point.
* **[[01:00:44](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=3644)]** The idea of the bisection method is very simple: we will define an iteration sequence of intervals. The starting interval is the interval $[a, b]$, the domain of the function, and we compute the midpoint of the interval. $p_0 = \frac{a_0 + b_0}{2}$. Then we have three possible cases: either the function value at $p_0$ equals to zero, then we are lucky, we have the root of the function and we are already done with the numerical method; or the other two cases, that one of the intervals $[a_0, p_0]$ or $[p_0, b_0]$ preserves the opposite sign property. Clearly, only one of the two intervals can have the opposite sign property. In the case if the function takes opposite signs at the ends of $[a_0, p_0]$, then we use this interval as the next interval in this sequence. Or the opposite situation: when the function takes opposite signs at the points $p_0$ and $b_0$, then use this interval as our next interval, and then we repeat this iteration with the new interval. And we have either the situation that after finitely many steps, $p_k$, the midpoint of the $k$-th interval, is a root of the function, then we stop generating the iteration, we are done, we have a root of the function; or the other situation: we have an infinite sequence of intervals with the property that the function has a root inside the interval.
* **[[01:03:07](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=3787)]** Look at the following figure: here, the starting interval is $[a_0, b_0]$, and the function takes opposite signs—the function value is positive at the left-hand point and it is negative at the right-hand point of this interval. Then we compute the midpoint of the interval and we check the sign of the function at $p_0$. Here, the sign is negative, so in the next step, we will use the left half of the interval and we repeat the procedure. This is the next step when we use this half of the interval. Again, we compute the midpoint and check the sign of the function at the midpoint, and again we get that the sign here is negative. So again, in the next step, we will use the left half of the interval. This is the new interval; compute the midpoint, and here the function value is positive. Function has an opposite sign at the right half of the interval, so we will use the right interval as the next interval, and then we continue with this iteration.
* **[[01:04:33](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=3873)]** In each step, we take half of the interval, so the length of the $k$-th interval will be the length of the starting interval divided by $2^k$. Therefore, the length goes to zero as $k \to \infty$. There is another famous theorem in calculus, the so-called Cantor's Nested Interval Theorem, which says that if we have a nested sequence of closed intervals with the property that the length of the intervals goes to zero, then there exists a point inside the starting interval with the property that the left endpoint and the right endpoints of the intervals both will converge to the point $p$ when $k \to \infty$, and $p$ is a common point of the intervals. So also, the midpoint will converge to the limit $p$.
* **[[01:05:47](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=3947)]** Suppose the case is then at the left endpoint, the function value is positive, and at the right endpoint, the function value is negative, and we generate the sequence of intervals using the bisection method. Then in each step, the function value at the left endpoint will be positive and at the right endpoint will be negative. And $p$ is the limit of the sequences $a_k$ and $b_k$; then the continuity of the function implies when $k \to \infty, a_k \to p$, therefore $f(a_k) \to f(p)$, and we have the inequality that $f(p) \ge 0$. And in the opposite way, since $f(b_k) < 0$ for each $k$, when $k \to \infty, f(b_k)$ converges to $f(p)$, therefore $f(p)$ should be less than or equal to zero. These two inequalities can be satisfied if and only if $f(p) = 0$. Okay, at the limiting point $p$, the function value should be equal to zero.
* **[[01:07:20](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=4040)]** But we have this situation that $p_k$, the half of the interval, is of course located in between $a_k$ and $b_k$, and $p$, the root, is in between $a_k$ and $b_k$. That means that the distance between $p_k$ and $p$ should be less than or equal to half of the length of the interval, therefore it is $\frac{b - a}{2^{k+1}}$. So we have a nice estimate for the error: since we use $p_k$ as the approximation of the root, the error $|p_k - p|$ will be less than or equal to this expression.
* **[[01:08:10](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=4090)]** So we prove the following theorem: if we have a continuous function with the opposite sign property at the left and right-hand points of the interval, then the bisection method generates the sequence $p_k$, the midpoints of the intervals, and the sequence $p_k$ converges to the root of the function, and the error of this approximation is less than or equal to $\frac{b - a}{2^{k+1}}$. Therefore, if we give a tolerance value $\varepsilon$, a positive number, and we want to guarantee that the error is less than $\varepsilon$, then it's enough to guarantee that this expression, the right-hand side in equation four, is less than $\varepsilon$, and then we can solve this inequality for $k$. So if $k$ is bigger than this expression, then we can be sure that the error of the approximation after $k$ steps of iteration will be less than the given $\varepsilon$. So that's the advantage of this bisection method: we can compute the number of steps which is needed in the bisection method to reach a certain precision of the approximation.
* **[[01:10:09](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=4209)]** Here is a numerical example: consider the function $e^x - 2\cos(x)$. We would like to solve the root of this function, we would like to approximate the root of this function. We cannot solve the root because this is a nonlinear equation and we don't have a solution technique to find the exact root, so we need to approximate it. It is easy to check that at zero, the value of the function is negative ($-1$), and at the point 1, the function value is positive. That means, and since the function is continuous, this implies that the function has a root in the interval $[0, 1]$, so we can apply the bisection method to approximate the root of the function. Let's pick an $\varepsilon = 10^{-5}$ and run the bisection method to reach this precision. Using the previous formula, we can compute that we need to perform at least 16 steps of iteration to get this accuracy of the approximation. Here is the numerical result: this is the starting interval $[0, 1]$, $p_k$ is the midpoint of the interval, and in the last column we printed out the function value at the midpoint. Here the length of the interval, you can see the difference between $b_k$ and $a_k$ is small because up to four decimal digits, the two values are the same, okay? And also the function value at the midpoint is of order $10^{-6}$, which is relatively close to zero.

### 2.5 Newton's Method

* **[[01:26:49](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=5209)]** In section 2.5, we introduce Newton's method. But before we do that, let's recall Taylor's Theorem from calculus. Suppose that $f$ is $n+1$ times continuously differentiable and fix a point $x_0$ in the domain of the function. Then for every $x$ which is not equal to $x_0$, there exists a point $c$ which depends on $x$, which belongs to the open interval spanned by $x$ and $x_0$. In other words, $c$ is a point in between $x$ and $x_0$ such that the function $f$ at the point $x$ equals the value of the Taylor polynomial at $x$ plus the error term. And the error term has the form: $\frac{f^{(n+1)}(c)}{(n+1)!}(x - x_0)^{n+1}$. And here is the formula of the $n$-th degree Taylor polynomial: $f(x_0) + f'(x_0)(x - x_0) + \frac{f''(x_0)}{2}(x - x_0)^2 + \dots + \frac{f^{(n)}(x_0)}{n!}(x - x_0)^n$. We will use this theorem several times later.
* **[[01:28:33](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=5313)]** But now we consider the nonlinear scalar equation $f(x) = 0$. But instead of solving the nonlinear equation, we replace the nonlinear equation with the first-order Taylor polynomial approximation around a point $p_0$. And this is the formula of the first-order polynomial: $f(p_0) + f'(p_0)(x - p_0)$, make it equal to zero and we can solve the linear equation. And this is the solution of the linear equation: $x = p_0 - \frac{f(p_0)}{f'(p_0)}$, assuming that the denominator is non-zero. That gives us the solution of the linear equation, and we hope that it's close to the solution of the original linear equation, but it is not equal in general. So we just make an iteration by this idea: we define a sequence, and the next element of the sequence $p_{k+1} = p_k - \frac{f(p_k)}{f'(p_k)}$. This sequence is called the Newton-Raphson's method or shortly, Newton's method.
* **[[01:30:15](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=5415)]** Here is a graphical illustration: consider the graph of $f(x)$, the red curve. We are looking for the root of this function. Pick a point $p_0$ and take the first-order polynomial approximation. What is that? That's a linear approximation, that's a tangent line, and we are looking for the root of the tangent line—the intersection of the line with the x-axis, this is $p_1$. And then we repeat: at the point $p_1$, again we consider the tangent line to the graph, this green line, and the intersection of this line with the x-axis gives us the next element of the sequence, $p_2$. And then we repeat, we continue with this iteration, and we can see in this figure that the sequence approaches to the root of the function.
* **[[01:31:16](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=5476)]** Let's test the numerical method on a numerical example. Consider the problem we have seen before, $e^x - 2\cos(x) = 0$, and we would like to solve it using Newton's method, and pick an initial value of the sequence $0.1$ and generate the Newton sequence. And we use the tolerance $10^{-5}$ and the stopping criteria is the following: when the distance between the consecutive terms in the sequence is less than the tolerance value, we stop generating the sequence. And here we see that the last two values of the sequence are the same up to the first six decimal digits; therefore, the distance, the difference between the two values in absolute value is less than $10^{-5}$ definitely. So Newton's method converges fast to the root of the function. Here at the last step, the function value is around $10^{-14}$ and very close to zero, that also demonstrates that we are close to the root of the function.
* **[[01:32:51](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=5571)]** But to prove the convergence of Newton's method, first we should observe that Newton's method is a one-step iteration with the function $g$, and $g(x) = x - \frac{f(x)}{f'(x)}$. If you take the fixed point iteration corresponding to this function $g$, we will get back the definition of Newton's method. How to prove the convergence of the fixed point sequence? We need to check the derivative of the function $g$ first. Compute the derivative of $g$: derivative of $x$ is 1 minus derivative of the fraction. We use the quotient rule: derivative of the numerator multiplied by the denominator gives us $(f')^2$ minus numerator multiplied by the derivative of the denominator, which is the second derivative of $f$, and divided by the square of the denominator. And divide the numerator term by term: first term gives us 1, and $1 - 1$ cancels in the computation. So after simplification, we get the last expression: $\frac{f(x)f''(x)}{(f'(x))^2}$.
* **[[01:34:28](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=5668)]** So if $p$ is a root, then $f(p) = 0$, so the numerator is zero, and assuming that the denominator is non-zero, the derivative is well-defined and equals to zero, so $g'(p) = 0$. ### 2.7 Order of Convergence

* **[[01:51:56](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=6716)]** In section 2.7, we will study the order of convergence of a sequence. Consider the following definition: let $p_k$ be a sequence which converges to $p$. We say that the order of convergence of the sequence is $\alpha$ if $\alpha$ is a real number which is greater than or equal to 1 and there exists a constant $C$ so that this inequality is satisfied: $|p_{k+1} - p| \le C \cdot |p_k - p|^\alpha$. How can we interpret the inequality? If we consider $p_k$ as the approximation of the limit $p$, then the left-hand side is the error of the $k+1$-th step of the approximation, and it is bounded by a constant $C$ times the $\alpha$-th power of the error of the $k$-th step of the iteration. And in the case of $\alpha = 1$, we also assume that the constant $C$ is less than 1.
* **[[01:53:04](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=6784)]** If you want to be more precise, we can say that the order of convergence is at least $\alpha$ because it is possible that we have this inequality, but maybe a similar inequality is satisfied with a bigger $\alpha$, okay? Another comment: when we divide the inequality by this last term, we can rewrite it in an equivalent way in this form: $\frac{|p_{k+1} - p|}{|p_k - p|^\alpha} \le C$, that means this fraction is bounded—if, of course, it's equivalent in the case when the denominator is non-zero.
* **[[01:53:54](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=6834)]** We say in the case when this inequality is satisfied with a certain $\alpha$ but not with any bigger $\alpha$, then we say that the order of convergence is exactly $\alpha$. * **[[01:54:24](http://www.youtube.com/watch?v=w1sFFbLjAOs&t=6864)]** In case of linear convergence, we have this inequality, and then we repeat it: estimate the second term here with again $C$ times the previous error, that gives $C^2$ times the previous error, and repeating the same type of estimate, we reach to the final estimate: $C^k \cdot |p_0 - p|$.
