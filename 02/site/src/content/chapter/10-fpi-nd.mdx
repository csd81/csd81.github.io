# §2.10 Fixed-Point Iteration in $n$ Dimensions

> 🚧 **Status:** content stub. **Widget to build:** `Newton2DContour` (contour plot of $\|\mathbf{f}(\mathbf{x})\|^2$ with click-to-start trajectories — used for both FPI and Newton in n-d). Copy prose from `/home/csd81/Desktop/02/Chapter_2_full.md` §2.10.

Same recursion $\mathbf{p}^{(k+1)} = \mathbf{g}(\mathbf{p}^{(k)})$, now with $\mathbf{g}\colon \mathbb{R}^n \to \mathbb{R}^n$. The book's running example is
$$\mathbf{g}(\mathbf{x}) = \begin{pmatrix} \tfrac{1}{4}(e^{x_1 x_2} + 3) \\ \tfrac{1}{3}(x_1 - x_2^2 - 1) \end{pmatrix},$$
arising from the system (2.26), with fixed point $(1, 0)^T$. At that point $\|\mathbf{g}'(1, 0)\|_1 = 1/3 < 1$, so the iteration converges locally.
